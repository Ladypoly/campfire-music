# Hand picks

Put songs you found yourself (e.g. a CC0 track on freemusicarchive.org) into `picks/YYYY-MM.txt`, one per line,
in the playlist format - they always go into that month's mix first:

    id | title | artist | m:ss | licence | page | audio | cover
    my-pick | Snowy Waltz | Some Artist | 3:10 | CC0 | https://freemusicarchive.org/... | https://.../file.mp3 | https://.../cover.jpg

`id` can stay empty (it is generated), `m:ss` can stay empty (it is measured), `cover` can stay empty (one is drawn).
Only CC0 / public domain music (or music you have permission for).
